iKit · Apple 生态 Agent 原生 CLI

一个 CLI，让 AI Agent 毫秒级直读你的 Notes / Tasks / Calendar / Photos / 会议。
Swift 原生，本地处理，数据不出 Mac。

安装 macOS · Homebrew

brew install liyuankui/tap/ikit

装完运行 ikit --version 验证。也可源码安装：git clone https://github.com/liyuankui/ikit.git && cd ikit && swift build -c release。首次使用需在系统设置授权（Notes/日历/照片/麦克风），见 安装引导文档。

🤖 Paste to your agent 让 AI 替你装 + 学会用法

请按这两个文档帮我安装并使用 iKit：
1. 安装+验证+权限引导：https://raw.githubusercontent.com/liyuankui/ikit/master/docs/agent-install-prompt.md
2. 装好后学会用（apple-kit 速查）：https://raw.githubusercontent.com/liyuankui/ikit/master/skills/apple-kit/SKILL.md

粘给 ZCode / Claude / WorkBuddy 等任意 AI 助手——它会自己抓文档、brew 安装、验证版本，再逐项引导你开启 Notes/日历/照片/麦克风权限。

⚡ Notes / Tasks / Calendar 毫秒读写

基于 EventKit 直连系统数据库，无需启动 App 即可毫秒级读写备忘录、提醒事项与日历；智能增量同步 + ID 隔离，写入原子化。

🖼 Photos 批量 OCR

Vision 框架批量识别截图文字，支持按截图/收藏智能筛选——几千张截图秒级变成可搜索文本。

🎙 Meet 本地转写

麦克风+系统音频双轨录制，Aggressive Gating 消回声，说话人自动分离；FunASR 完全离线转写，零云端零泄露。

🤖 Agent-First 设计

JSON-First 输出、Progressive --help、错误自带 💡 Try: 自纠错建议、[exit:N | Xs] 元数据——为 Agent 消费而生。

🧰 开箱即用 Skills

内置 apple-kit / meeting-recorder 两个 Agent Skill，拷进 ~/.agents/skills/ 即让你的 AI 助手全功能操控 Apple 生态。

⏰ Timer 定时任务

LaunchAgents 定时提醒：到点打开文档/会议链接/运行命令，登录自动加载，执行可确认可留痕。
